# نظام نقطة بيع المخبز 🍞 — دليل التشغيل

نظام كامل لإدارة طلبيات المخبز: شاشة كاشير للطلب، شاشة فرن لحظية للخباز، إدارة منتجات وأسعار، وتقارير مبيعات يومية/أسبوعية/شهرية/سنوية.

---

## 1) ما الذي تحتاجه

- لابتوب (للكاشير) — ويندوز أو ماك.
- موبايل (للخباز) فيه متصفح (Chrome / Safari).
- تثبيت **Node.js** على اللابتوب (مرة واحدة فقط). نزّله من: https://nodejs.org (اختر النسخة LTS).

> هذه الخطوة الوحيدة التي تحتاج إنترنت فيها (تثبيت Node.js وتثبيت مكتبات المشروع لأول مرة). بعد ذلك البرنامج يعمل بالكامل **بدون إنترنت**.

---

## 2) التثبيت (مرة واحدة)

1. افتح **Terminal** (ماك) أو **Command Prompt / PowerShell** (ويندوز).
2. انتقل لمجلد المشروع، مثلاً:
   ```
   cd Desktop/bakery-pos
   ```
3. ثبّت المكتبات:
   ```
   npm install
   ```
   (سيحمّل كل ما يحتاجه المشروع، يحتاج إنترنت هذه المرة فقط).

---

## 3) تشغيل البرنامج

كل يوم، لتشغيل النظام:

```
npm start
```

سترى رسالة شبيهة بهذه:

```
✅ السيرفر يعمل الآن!
   على هذا اللابتوب (الكاشير): http://localhost:3000
   من الموبايل (الخباز) افتح:   http://192.168.1.5:3000/kitchen.html
```

- **على اللابتوب**: افتح المتصفح (Chrome مثلاً) واذهب إلى `http://localhost:3000` — هذه شاشة الكاشير.
- **على الموبايل**: افتح المتصفح واذهب إلى نفس عنوان الـ IP الظاهر في الرسالة (مثل `http://192.168.1.5:3000/kitchen.html`).

⚠️ اتركْ نافذة الـ Terminal مفتوحة طول وقت العمل — هي السيرفر، إذا أغلقتها يتوقف البرنامج عن العمل على كل الأجهزة.

💡 **نصيحة:** على الموبايل، بعد فتح الرابط اضغط على خيارات المتصفح ثم "إضافة إلى الشاشة الرئيسية" (Add to Home Screen) — بتصير شاشة الفرن كأنها تطبيق منفصل بضغطة واحدة.

---

## 4) ربط اللابتوب والموبايل بدون واي فاي خارجي (Hotspot)

إذا ما في شبكة واي فاي بالمحل، اعمل نقطة اتصال من اللابتوب نفسه:

**ويندوز:** الإعدادات ⚙️ ← الشبكة والإنترنت ← نقطة الاتصال المحمولة (Mobile Hotspot) ← شغّلها.
**ماك:** تفضيلات النظام ← مشاركة الإنترنت (Internet Sharing) ← فعّلها عبر Wi-Fi.

بعدها وصّل الموبايل على شبكة اللابتوب هاي (رح يظهر اسمها وكلمة سرها بالشاشة)، وافتح نفس عنوان IP الظاهر بالـ Terminal.

> ملاحظة: عنوان الـ IP بيتغيّر كل مرة تشغّل الهوتسبوت من جديد أحياناً — دايماً رجّع شوف الرسالة بالـ Terminal لآخر عنوان صحيح.

## 5) طريقة الاستخدام

### شاشة الكاشير (اللابتوب)
- اضغط على أيقونة الصنف لإضافته للطلبية (كل ضغطة = +1).
- لإدخال كمية كبيرة مباشرة: اضغط "✎" فوق الصنف واكتب الرقم.
- بالسلة (يسار الشاشة): تكبير/تصغير الكمية بـ + و −، أو حذف الصنف بـ ✕.
- اضغط **إرسال الطلبية 🚀** — بترسل فوراً لشاشة الخباز مع صوت تنبيه عنده (إذا كانت الطلبية تحتوي معجنات).
- طلبيات الخبز فقط (بدون معجنات) لا تذهب لشاشة الخباز أصلاً، لأنها لا تحتاج تحضير.
- بالأسفل "طلبيات مفتوحة" — تقدر تضغط "تم التسليم" لما الزبون ياخذ طلبيته (هذا فقط لتتبع الفرن، البيع والسعر محسوبين من لحظة إرسال الطلبية لأن الدفع يصير عادة عند الطلب).

### شاشة الفرن (الموبايل)
- بتعرض فقط أصناف المعجنات المطلوبة (مش الخبز).
- عند وصول طلبية جديدة: صوت تنبيه + اهتزاز + توهج على البطاقة.
- لما يخلص الخباز التحضير، يضغط **✅ تمّ التحضير** — بيرجع صوت تنبيه لشاشة الكاشير.
- أول ما تفتح الشاشة، اضغط أي مكان فيها مرة واحدة (لتفعيل الصوت — متطلب من المتصفح).

### صفحة إدارة المنتجات (⚙️ المنتجات)
- إضافة صنف جديد: أيقونة (إيموجي) + اسم + فئة (خبز/معجنات) + سعر.
- تعديل اسم/فئة/سعر أي صنف موجود ثم اضغط "حفظ".
- "إيقاف" يخفي الصنف من شاشة الكاشير بدون حذف بياناته القديمة من السجلات.

### صفحة التقارير (📊 التقارير)
- اختر الفترة: اليوم / الأسبوع / الشهر / السنة، وممكن تختار تاريخ معيّن بالأعلى.
- بتشوف: عدد الطلبيات، إجمالي المبيعات، متوسط الطلبية، المبيعات حسب الفئة (خبز/معجنات)، الأصناف الأكثر مبيعاً، ومخطط مبيعات حسب اليوم.

## 6) بنية المشروع (للفهم البرمجي)

```
bakery-pos/
  server/
    db.js        → تعريف قاعدة البيانات SQLite والجداول
    index.js     → السيرفر: REST API + الاتصال اللحظي (Socket.io)
  public/
    cashier.html/js/css   → شاشة الكاشير
    kitchen.html/js/css   → شاشة الفرن
    admin.html/js/css     → إدارة المنتجات
    reports.html/js/css   → التقارير
    sounds.js             → مولّد الأصوات (Web Audio API، بدون ملفات صوتية)
  bakery.db      → ملف قاعدة البيانات (يُنشأ تلقائياً عند أول تشغيل، فيه كل الطلبيات والمبيعات)
```

**قاعدة البيانات (SQLite):**
- `products` — الأصناف والأسعار والأيقونات.
- `orders` — كل طلبية (رقمها، حالتها، إجماليها، وقتها).
- `order_items` — تفاصيل كل صنف داخل كل طلبية (لحساب التقارير بدقة).

**لماذا SQLite؟** قاعدة بيانات ملف واحد، لا تحتاج تثبيت سيرفر قاعدة بيانات منفصل، مناسبة جداً لمشروع بحجم محل واحد ومضمونة لا تفقد بيانات حتى عند انقطاع الكهرباء المفاجئ (بفضل وضع WAL المفعّل بالكود).

**النسخ الاحتياطي:** من وقت لوقت، انسخ ملف `bakery.db` (مثلاً على فلاشة أو إيميل) للحفاظ على سجل المبيعات.

---

## 7) أخطاء شائعة وحلولها

| المشكلة | الحل |
|---|---|
| `npm install` يعطي خطأ | تأكد إنك متصل بإنترنت، وإن Node.js مثبّت (`node -v` بالـ Terminal) |
| الموبايل ما بيتصل بالعنوان | تأكد إن الموبايل واللابتوب على نفس الشبكة (واي فاي أو هوتسبوت)، وتأكد من العنوان الظاهر بالـ Terminal بالضبط |
| لا صوت بشاشة الفرن | اضغط مرة واحدة بأي مكان بالشاشة لتفعيل الصوت (متطلب أمان من المتصفح) |
| السيرفر توقف | شغّل `npm start` من جديد بنفس مجلد المشروع |
