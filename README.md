# Bakery-bos (Bakery POS & Order Management System)

A real-time point of sale (POS) and order management system built specifically for bakeries, powered by **Node.js** and **SQLite**.

## 🚀 Features

* **Real-Time Order Routing:** Instant synchronization between cashiers and kitchen displays.
* **Live Kitchen Tracking:** Manage order statuses seamlessly through stages: 
  `Pending ➔ In Oven ➔ Ready`
* **Historical Price Integrity:** Ensures past orders maintain their accurate historical pricing regardless of future catalogue updates.
* **Advanced Sales Analytics:** Comprehensive insights and reporting across **daily, weekly, and monthly** intervals.

## 🛠️ Tech Stack

* **Backend:** Node.js, Express (or your chosen framework)
* **Database:** SQLite
* **Architecture:** Real-time event-driven flow
